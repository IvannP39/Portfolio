VIOK — Connecter les Générations

La Mission

VIOK est une solution complète conçue pour rompre l'isolement social des aînés en simplifiant radicalement l'accès à la communication numérique. L'idée est née d'un constat simple : la technologie actuelle est souvent trop complexe pour nos grands-parents. VIOK transforme une tablette ordinaire en un compagnon simple, rassurant et toujours connecté à la famille.

React Native Supabase Expo RevenueCat PostgreSQL TypeScript

Fonctionnalités Clés

Photos Instantanées

Les souvenirs partagés par la famille s'affichent automatiquement en mode diaporama, sans aucune manipulation requise du senior.

Planning Partagé

Synchronisation des rendez-vous médicaux et des visites familiales. Un rappel visuel clair pour ne jamais rien oublier.

Appels Vidéo

Une interface d'appel simplifiée "en un clic" pour se voir et se parler sans stress technique.

Messages Doux

Des petits mots d'affection affichés en grand sur le tableau de bord pour illuminer la journée.

Une Expérience Double

Mode Sénior (Tablette)

  • Gros caractères ultra-lisibles
  • Navigation intuitive sans menus complexes
  • Météo et heure en temps réel
  • Mode "Kiosque" pour éviter les erreurs de manipulation

Mode Famille (Smartphone)

  • Gestion centralisée de la tablette à distance
  • Upload de photos et gestion du calendrier
  • Notifications de lecture et d'activité
  • Abonnement Premium via RevenueCat

Architecture Technique

Le projet repose sur une architecture moderne et scalable :

  • Frontend : Développement cross-platform avec React Native et TypeScript pour une performance native sur iOS et Android.
  • Backend : Utilisation de Supabase pour la base de données temps réel, l'authentification et le stockage des images.
  • Paiements : Intégration de RevenueCat pour la gestion des abonnements in-app.
  • Déploiement : Pipeline CI/CD via Expo Application Services (EAS).
