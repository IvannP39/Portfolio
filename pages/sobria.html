SOBRIA — Green AI Benchmarking

L'IA Responsable

SOBRIA (Sobriety-Oriented Benchmarking for Responsible AI) est un outil d'audit d'entreprise (On-prem/Cloud) conçu pour mesurer l'empreinte environnementale et la performance des modèles de langage (LLM). Il permet de quantifier précisément ce que coûte une inférence en termes d'énergie, d'eau et de carbone.

Python 3.10+ Docker & Compose CodeCarbon OpenCV / Data Viz Inférence API (OpenAI-compatible) Markdown/PDF Reporting

Métriques Mesurées

Énergie

Consommation en kWh par requête (mesure réelle via capteurs matériels).

Carbone

Estimation de l'empreinte CO₂ basée sur l'intensité carbone locale.

Ressources

Utilisation intensive du GPU, CPU et de la RAM pendant l'inférence.

Performance

Latence (Time to First Token), débit et précision des réponses.

Fonctionnement Technique

SOBRIA ne déploie pas de modèles lui-même. Il agit comme une sonde externe qui interroge vos serveurs d'inférence existants (Ollama, vLLM, llama.cpp, etc.) tout en surveillant la consommation matérielle en temps réel.

Points Clés de l'Architecture :

  • Isolation totale : Déployé via Docker, aucune donnée ne quitte votre infrastructure.
  • Configuration hiérarchique : CLI, YAML, Variables d'environnement pour une flexibilité maximale.
  • Comparaison Théorique : Compare les mesures réelles avec des modèles théoriques de consommation basés sur le nombre de paramètres.
  • Datasets intégrés : SQuAD, Sentiment Analysis, General Q&A pour des tests standardisés.

Exemple d'utilisation :

# Lancer un audit sur Llama 3 avec 10 échantillons
docker compose run sobria --model llama3 --task qa/simple_100 --max-samples 10

Livrables d'Audit

À la fin de chaque session de benchmarking, SOBRIA génère automatiquement des rapports détaillés dans le dossier output/ :

  • CSV : Données brutes par requête pour analyse approfondie.
  • JSON : Synthèse structurée pour intégration dans des dashboards.
  • Markdown/PDF : Rapports lisibles par l'humain avec graphiques et recommandations.
